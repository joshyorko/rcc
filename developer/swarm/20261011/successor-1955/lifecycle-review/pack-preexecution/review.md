## Immediate admission findings

- **No-go until root guards are complete.** `mode700` checked only the leaf directory mode and file type, not UID/GID. Worker checked its home once before work and only on the success path afterward; scheduler postchecked only the home, also after successful workers. No all-owned-root/enclosing strict-0700 preflight and strict postguard on every result path. The prior baseline import's 0700→0750 failure remains preserved and is not waived.
- **No fresh consumer CAS proof.** New worker homes are created, but there is no explicit emptiness/absence check for artifacts/content/materialization state before each acquisition. Preflight must reject contaminated roots without repairing/chmodding them.
- **Packed index cross-bind is incomplete.** Constructor now resolves and hashes the standard object-index and checks pack entries by digest/size/count, but does not bind/validate descriptor media type. `GetObject` sends every non-object media request to base, so wrong-media requests aren't explicitly rejected. Add a mismatched-media negative and reject a descriptor whose media type or digest/size doesn't match the standard index.
- **Whole pipeline timing starts too late.** `newPackedProvider` (including full-pack hash and index validation) runs before CPU profile and acquire timer start. Include construction in the measured boundary or label it separately and count it in whole arm timing.
- **Lease proof is too permissive.** `leaseExists` maps every `Lstat` failure to absence. Treat only `errors.Is(err, fs.ErrNotExist)` as released; permission, symlink-loop, and I/O errors must fail. Keep checking cleanup after `ExecuteWithStreams` returns, including child-error paths.
- **Receipt failures can be lost.** `appendReceipt` discards append/fsync errors; early worker failures can return without recording an arm failure. Scheduler ignores worker-log and worker-exit receipt write errors. Preserve incremental receipts and stop at first failure while reporting persistence failures.
- **Fixture compatibility is real but narrow.** Host Python is probed by executing the supplied real interpreter, and the frozen `Acquirer` performs current-worker preflight; `LocalMaterializer` invokes real `validateMaterializedCompatibility` for the materialized Python. `ExecuteWithStreams` uses the materialization root as child CWD (confirmed in frozen `environmentlifecycle/execute.go`, SHA `2c03a4f3d3d215d6dd7cac08bdaf52299c894663c07af163c157f4da843e7a66`), so relative verifier paths are valid. Still, the fixture's OS/kernel/libc minimums (`"1"`) and filesystem max-path `1` are intentionally permissive/synthetic and must not be presented as broad compatibility evidence.
- Existing packed path has useful safeguards: bounded index/pack sizes, root component `O_NOFOLLOW` traversal, regular-file `fstat`, pinned index and full-pack hashes, exact contiguous frame ranges, per-frame hash, separate output buffers, provider `Close` on normal worker, and independent corruption/truncation/symlink/wrong-size/digest/out-of-range negatives. Keep these, add malformed digest/media and failure-path resource/receipt checks.
